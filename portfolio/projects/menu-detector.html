Muammo

Tayyor datasetlar (masalan, Food-101) asosan G'arb taomlaridan iborat — ularda palov ham, kabob/shashlik ham yo'q. Shu sababli tayyor modellar bizning milliy taomlarimizni taniy olmaydi. Maqsad: kichik, tez ishlaydigan va o'zbek taomlarini ham biladigan klassifikator yaratish.

1. Dataset va class consolidation

7 ta papkadagi rasmlar 6 ta semantik klassga birlashtirildi. Pancakes va chocolate_cake alohida o'rganilganda bir-biri bilan chalkashadi, ammo menyu nuqtai nazaridan ikkalasi ham "desert" — shu sababli ular bitta klassga guruhlandi.

CUSTOM_CLASS_MAPPING = {
    'hot_dog': 'hot_dog',
    'kebab': 'kebab',            # o'zim yig'gan
    'pilaf': 'pilaf',            # o'zim yig'gan
    'pancakes': 'dessert',       # label grouping
    'chocolate_cake': 'dessert',

}

Scraping orqali kelgan rasmlar orasida buzuq fayllar uchraydi. Custom FoodDataset klassi bunday rasmni o'tkazib yuborib, keyingisini oladi — o'qitish jarayoni to'xtab qolmaydi.

2. Model arxitekturasi

MobileNetV2 tanlandi: u yengil (≈3.5M parametr), telefon va brauzerda ham tez ishlaydi. ImageNet'da o'qitilgan og'irliklar "backbone" sifatida olinib, faqat oxirgi klassifikator qatlami 6 ta chiqishga almashtirildi.

model = mobilenet_v2(weights="IMAGENET1K_V1")
model.classifier[1] = nn.Linear(model.classifier[1].in_features, NUM_CLASSES)

criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)

4. Inference — modelni ishlatish

Saqlangan model yuklanadi, foydalanuvchi rasm yuklaydi, model esa eng ehtimolli klasslarni foizlarda qaytaradi:

image_tensor = transform(image).unsqueeze(0).to(device)
with torch.no_grad():
    probs = torch.softmax(model(image_tensor), dim=1)[0]
    topk  = torch.topk(probs, 4)

Nimalarni o'rgandim

Data — eng muhim qism

Modelning sifati birinchi navbatda datasetga bog'liq. Rasmlarni yig'ish, buzuqlarini filtrlash va klasslarni to'g'ri guruhlash arxitektura tanlashdan kam vaqt olmadi.

Transfer learning

Noldan o'qitish o'rniga tayyor backbone'dan foydalanish 5 mingta rasm bilan ham yuqori natija beradi va GPU vaqtini tejaydi.

Best checkpoint saqlash

Val aniqlik epochlar orasida tebranadi (4-epochda 81.9%). Shuning uchun faqat eng yaxshi natijani saqlash muhim.

Train va inference farqi

Inference paytida model.eval() va torch.no_grad() ishlatish, preprocessing'ni aynan train'dagidek qoldirish shart.

Keyingi qadamlar

  • Data augmentation (random flip, crop, color jitter) — overfitting'ni kamaytirish va val aniqlikni barqarorlashtirish uchun.
  • Confusion matrix — qaysi taomlar bir-biri bilan chalkashayotganini ko'rish.
  • Yangi klasslar: manti, lag'mon, somsa, sho'rva.
  • Deploy: Gradio / Streamlit web-ilova yoki Telegram bot ko'rinishida.
